阴阳师工具（多开 + 窗口排列 + 声音聚焦）使用说明
==================================================

一、这是什么
    一个原生 Windows 图形界面工具（WPF 现代化深色界面），整合以下功能：
      1. 多开：以 D:\Netease\yys 为工作目录启动 bin\onmyoji.exe，实现多开（实例间隔 8 秒）
      2. 窗口排列：把已打开的阴阳师窗口按网格整齐排列（探测-定位两阶段，适配客户端尺寸锁定）
      3. 声音跟随聚焦：鼠标/焦点切到哪个游戏窗口，就恢复该窗口音量，其余自动调小到 15%（可开关）
      4. 一键关闭：点击按钮优雅退出所有阴阳师游戏窗口（自动点击确认框，超时再强制结束）

    基于 .NET Framework 4.x (C# WPF) 开发，Windows 自带运行环境，无需安装任何额外运行时。
    界面为深色卡片式现代化布局：圆角卡片分区、渐变主按钮、自绘列表、现代化开关。

二、文件说明
    阴阳师工具.exe   主程序（双击运行，需要管理员权限，会自动弹出 UAC 确认）
    阴阳师工具.cs    WPF 版源码
    app.manifest     管理员权限清单
    build.bat        一键重新编译脚本（修改源码后双击即可重新生成 exe）
    阴阳师工具_winforms_v1.cs / .exe  旧版 WinForms 源码与程序备份

三、使用方法
    1. 多开
       - 在「目标开数」输入想同时运行的游戏窗口数量（1-10）
       - 点击「开始多开」，程序会先统计当前已开实例数，只补开差额
       - 每个新实例间隔 8 秒启动，日志会实时显示进度
    2. 窗口排列
       - 先启动游戏，点击「刷新列表」查看识别到的阴阳师窗口
       - 在「每行窗口数」选择一行放几个（1-4）
       - 点击「排列窗口」，程序先探测客户端可接受的最大尺寸，再按网格自动排布
    3. 声音跟随聚焦
       - 打开「声音跟随聚焦」开关后，程序每 0.5 秒检测前台窗口
       - 前台是某游戏窗口时恢复其原始音量，其余游戏调小到 15%；全部失焦时全部调小
    4. 一键关闭
       - 点击「一键关闭所有游戏窗口」，程序依次向每个游戏窗口发送退出请求
       - 自动点击确认框的「确定」按钮，3 秒内未退出则强制结束
    5. 运行日志：下方日志区会显示每次操作的详细结果，方便排查

四、注意事项
    - 程序必须管理员权限运行（操作其他进程窗口/音量需要），已内置 UAC 提权清单
    - 多开仅拉起多个游戏进程，不修改任何游戏文件
    - 音量调节走系统音频层（WASAPI），不触碰游戏文件，无封禁风险
    - 识别逻辑会排除工具自身窗口，标题/进程匹配已收紧，正常不会误判
