阴阳师工具（多开 + 窗口排列 + 声音聚焦）使用说明
==================================================

一、这是什么
    一个原生 Windows 桌面工具（C# WPF / .NET Framework 4.x），把多开、窗口排列、
    声音跟随聚焦、一键关闭整合进同一个单屏控制台，不需要在多个页面之间来回切换。

    界面采用「和纸 · 墨 · 朱印」浅色视觉：
      - 暖白纸面 + 墨色文字，朱砂色只用于主操作与印章标记，长时间看也不刺眼
      - 左侧三张操作卡片（多开 / 排列 / 声音），右侧运行实例列表与终端式日志
      - 顶栏集中显示运行实例数、置顶、最小化与关闭；底栏显示权限状态和说明入口
      - 每个功能一屏可达，日志常驻可见，不再挤在页面底部

    核心功能：
      1. 多开：以 D:\Netease\yys 为工作目录启动 bin\onmyoji.exe，实例间隔 8 秒
      2. 窗口排列：把已打开的阴阳师窗口按网格整齐排列（探测-定位两阶段，适配客户端尺寸锁定）
      3. 声音跟随聚焦：鼠标/焦点切到哪个游戏窗口，就恢复该窗口音量，其余自动调小到 15%（可开关）
      4. 一键关闭：优雅退出所有阴阳师游戏窗口（自动点击确认框，超时再强制结束）

三、使用方法
    1. 多开
       - 在「目标开数」里用 − / + 调整，或直接输入 1-10
       - 点击「开始多开」，程序先统计当前实例数，只补开差额
       - 每个新实例间隔 8 秒启动，日志会实时显示进度
       - 多开在后台执行；需要中止时点右上角「取消」或按 Esc，已启动的实例不会被回滚

    2. 窗口排列
       - 先启动游戏，点「刷新列表」（或按 F5）查看识别到的窗口
       - 在「每行窗口数」里点选 1 / 2 / 3 / 4
       - 点「排列窗口」，程序先探测客户端可接受的最大尺寸，再按网格自动排布
       - 可重复点击微调；排列过程中鼠标会显示等待状态，也可从右上角取消

    3. 声音跟随聚焦
       - 打开「声音跟随聚焦」开关后，程序每 0.5 秒检测前台窗口
       - 前台是某游戏窗口时恢复其音量，其余游戏调小到 15%；全部失焦时全部调小
       - 关闭开关或退出程序时，会把仍在运行的游戏音量恢复到 100%
       - 状态会显示「监控中 / 已暂停」

    4. 一键关闭
       - 在「运行实例」卡片底栏右侧点「关闭所有窗口」，会先弹出确认
       - 程序依次向每个游戏窗口发送退出请求，自动点击「退出游戏」确认框
       - 3 秒内未退出则强制结束该进程；可点右上角取消

    5. 运行日志
       - 记录每次多开、排列、声音开关、关闭与识别的结果，方便排查
       - 「清空」只清空界面日志；声音跟随不再生成独立的 audio_log.txt

    6. 快捷键
       - F5：刷新实例列表
       - Esc：关闭「关于 / 确认」弹层；没有弹层时取消当前后台操作

五、注意事项
    - 程序必须管理员权限运行（操作其他进程窗口/音量需要），已内置 UAC 提权清单
    - 底栏会显示「管理员权限 / 普通权限」；普通权限下部分窗口操作可能失败
    - 多开仅拉起多个游戏进程，不修改任何游戏文件
    - 音量调节走系统音频层（WASAPI），不触碰游戏文件，无封禁风险
    - 识别逻辑会排除工具自身窗口，只认 onmyoji.exe / yys.exe 与「阴阳师」标题
    - 如果工具被其他窗口遮挡，点右上角的图钉按钮置顶
    - 多开目标上限为 10；每行窗口数为 1-4
    - 长操作都在后台线程执行，界面不会卡死；取消不会回滚已经启动的实例或已经移动的窗口

六、开发与自检
    - 自检：对无清单副本运行 `阴阳师工具.exe --selftest`，会检查输入、网格、配置、
      进程/窗口识别、WASAPI 枚举与声音服务，并写 selftest.log（已被 .gitignore 忽略）
    - UI 冒烟：用假服务编译 tools\UiShot.cs，可离屏截图并执行 26 项交互检查，
      不会操作真实游戏窗口或音量
