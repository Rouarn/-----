# 阴阳师工具（OnmyojiTools）

一个原生 Windows 桌面小工具：把「多开、窗口排列、声音跟随聚焦、一键关闭」收进同一个单屏控制台。C# WPF / .NET Framework 4.x，界面采用「和纸 · 墨 · 朱印」浅色视觉。

> 仅用于个人学习与自用；与网易 / 阴阳师官方无关。工具只做窗口、进程与系统音量层操作，不修改游戏文件。

## 功能

- **多开**：以指定游戏目录启动 `bin\onmyoji.exe`，只补开差额实例，默认间隔 8 秒。
- **窗口排列**：按 1 / 2 / 3 / 4 列网格排列已打开的游戏窗口，先探测可用尺寸再定位。
- **声音跟随聚焦**：前台切到哪个游戏窗口，就恢复该窗口音量，其余降到 15%；可开关。
- **一键关闭**：向所有实例发送退出请求，自动处理确认框，超时后强制结束。
- **运行日志**：多开、排列、声音、关闭与识别结果实时写入，方便排查。

## 环境

- Windows 10 / 11
- .NET Framework 4.x
- 管理员权限（窗口与系统音量操作需要）
- 阴阳师 PC 客户端；默认工作目录 `D:\Netease\yys`，可在界面中修改

## 构建

```bat
build.bat
```

生成 `阴阳师工具.exe`。源码在 `src/`，编译产物、日志与本机配置不会提交到仓库。

## 使用

1. 以管理员身份运行程序。
2. 在左侧卡片设置游戏目录、目标开数与每行窗口数。
3. 使用「开始多开」「排列窗口」「声音跟随聚焦」「关闭所有窗口」。
4. 详细说明见 [`使用说明.txt`](./使用说明.txt)。

## 说明

- 多开只拉起多个游戏进程，不修改任何游戏文件。
- 音量调节走系统音频层（WASAPI），不注入游戏进程。
- 仓库不包含游戏本体、账号信息或任何第三方私有资源。
